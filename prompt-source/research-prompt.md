순수 HTML, CSS, JavaScript만으로 강의용 웹 슬라이드를 구현하는 최적의 방법을 리서치하세요.
외부 라이브러리(Reveal.js 등)는 참고만 하고, 최종 구현은 순수 바닐라로 가능해야 합니다.

다음 4개의 주제를 서브에이전트로 병렬 리서치하세요:

## Agent 1: 다크모드 강의용 레이아웃 & DOM 구조

- 강의 슬라이드에 최적화된 16:9 full-viewport 레이아웃 구현 방법
- 다크 배경(#0d1117 계열)에서 가독성 높은 컨테이너 구조 설계
- 콘텐츠 영역 / 타이틀 영역 / 하단 네비게이션 영역 분리 구조
- 반응형 슬라이드 구현 방법 (vw/vh 단위, aspect-ratio 유지)

## Agent 2: 핵심 내용 강조 시각화 기법

- 다크 배경에서 핵심 키워드를 눈에 띄게 만드는 CSS 기법 (형광 컬러, glow 효과, 배지 등)
- 코드 블록을 강의 슬라이드에 보기 좋게 표시하는 방법
- 아이콘 없이 텍스트만으로 계층 구조를 시각적으로 표현하는 방법
- 강조색 팔레트 추천 (다크모드 기준, 시인성 높은 조합)

## Agent 3: 슬라이드 전환 & 네비게이션

- 키보드(←→, Space) 및 터치/스와이프 네비게이션 구현
- 강의에 적합한 전환 애니메이션 (fade, slide 중 집중 방해 없는 방식)
- 슬라이드 번호 / 진행률 표시바 구현
- 전환 중 추가 입력 막는 이벤트 잠금 처리

## Agent 4: 강의용 콘텐츠 빌드 효과

- 슬라이드 진입 시 요소를 순서대로 등장시키는 방법 (data-step 방식 등)
- 텍스트/리스트 항목 순차 reveal 구현
- 강조 효과가 과하지 않으면서 학습자 시선을 유도하는 애니메이션 패턴
- GPU 가속 활용법 (transform, will-change 속성)
