Chapter 2 · RAG 개념

RAG란? —
오픈북 시험

AI에게 책을 펼쳐놓고 시험 보게 하는 기술. 외부 문서를 실시간으로 참조해 더 정확한 답변을 만듭니다.

  • 기존 LLM: 학습한 지식에만 의존해 답변 생성
  • RAG형 LLM: 외부 문서·웹 검색으로 답변 생성

Chapter 2 · LLM 한계 극복

RAG vs Fine-tuning

두 가지 접근법의 차이를 이해하면 RAG가 왜 필요한지 명확해집니다

RAG
외부 데이터 주입
외부 데이터를 프롬프트에 주입해 LLM 답변 품질을 향상시키는 방식
  • 외부 지식 추가로 정확도·신뢰도 향상
  • 추가 학습이 필요하지 않음
  • 검색된 정보의 품질에 의존
Fine
모델 재학습
모델 자체를 특정 데이터로 재학습시켜 특정 작업 성능을 높이는 방식
  • 특정 작업 성능 극대화 가능
  • 추가 학습 데이터 및 비용 필요
  • 학습 데이터 외 질의엔 취약
후츠릿 · RAG 완전 정복
  1. R
    Retrieval — 검색
    필요한 정보를 외부 문서·데이터베이스에서 찾아오는 것
  2. A
    Augmented — 증강
    찾아온 정보를 프롬프트에 추가해 질문을 강화하는 것
  3. G
    Generation — 생성
    증강된 프롬프트로 LLM이 정확한 근거 기반 답변을 생성하는 것
Chapter 2 · RAG 구조

RAG 파이프라인 2종

RAG는 두 단계 파이프라인으로 구분된다

Index
Indexing Pipeline
문서를 검색 가능한 형태로 변환·저장하는 사전 준비 단계
  • 실행 시점: 사전 준비 (1회성)
  • 흐름: 문서 → 청킹 → 임베딩 → Vector DB
  • 한 번만 실행하면 이후 재사용 가능
Query
Query Pipeline
질문에 맞는 정보를 검색하고, 프롬프트를 증강해 답변을 생성하는 실시간 단계
  • 실행 시점: 질문마다 실시간
  • 흐름: 질문 → 검색 → 증강 → LLM → 답변
  • Indexing 결과를 기반으로 매번 실행

Query 3단계 흐름

검색(Retrieve)하고 증강(Augment)해서 답변을 생성(Generate)한다

질문마다
실시간으로
실행

Indexing 결과를 기반으로 매번 동작

  • R
    Retrieve — 검색
    사용자 질문을 동일한 임베딩 모델로 벡터화 → Vector DB에서 유사도 높은 청크를 반환합니다
  • A
    Augment — 증강
    검색된 청크(분할된 텍스트)를 프롬프트에 주입해 LLM의 컨텍스트를 보강합니다
  • G
    Generate — 생성
    증강된 프롬프트로 LLM이 근거 기반의 정확한 최종 답변을 생성합니다

Chapter 4 · Retrieve

기존 검색 vs 시맨틱 서치

키워드 일치가 아닌, 문장의 의미 기반으로 결과를 찾는 검색 기법

기존
키워드 검색
입력한 단어가 문서에 그대로 포함되어 있을 때만 결과를 반환합니다.
  • "금리" 검색 시 "이자율" 문서 누락
  • 동의어·유사어 매칭 불가
  • 표현이 달라지면 검색 실패
시맨틱
시맨틱 서치
질문을 벡터로 변환해 Vector DB에서 의미가 가까운 청크를 유사도 기반으로 반환합니다.
  • "돈 빌리면 이자 얼마야?" → "금리" 청크 반환
  • 키워드 달라도 의미 유사하면 검색 성공
  • 유사도 점수로 관련도 순위 결정
사용자 쿼리를 동일한 임베딩 모델로 벡터화한 뒤 Vector DB에서 유사도 높은 청크를 반환

증강 —
프롬프트 강화

검색된 청크를 프롬프트에 주입해 LLM의 컨텍스트를 보강합니다. 질문만 있던 프롬프트가 근거 자료를 포함한 강화된 프롬프트로 바뀝니다.

증강 전

생성 — 근거 기반 답변

검색된 청크들을 바탕으로 LLM이 최종 답변을 생성한다

1
청크 검색 완료
벡터 공간에서 질문과 가장 유사한 청크 Top-K개를 반환합니다.
  • 청크 1: 관련 문서 조각
  • 청크 2: 관련 문서 조각
  • 청크 3: 관련 문서 조각
2
프롬프트 증강
검색된 청크들을 컨텍스트로 묶어 LLM에 전달합니다.
  • 참고자료 + 질문 형태로 구성
  • LLM이 근거를 바탕으로 판단
3
LLM 답변 생성
주입된 청크 기반으로 LLM이 환각 없이 정확한 답변을 생성합니다.
  • 근거 기반 신뢰도 높은 답변
  • 출처 추적 가능
주입된 프롬프트에 의해 LLM이 근거 기반으로 최종 답변 생성 — Hallucination 대폭 감소
